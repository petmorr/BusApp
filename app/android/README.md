# Android platform folder

The native Android project is generated by `flutter create` and is not
checked into this scaffold. Run the following from `app/` to materialise it:

```bash
flutter create --platforms=android --project-name supporters_bus_app .
```

Then update `android/app/build.gradle` to set:

- `minSdkVersion 24` (Android 7.0).
- `targetSdkVersion 34` (or current Flutter default).

Add the `google-services.json` you receive from `flutterfire configure` to
`android/app/`.
