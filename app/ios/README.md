# iOS platform folder

The native iOS project is generated by `flutter create` and is not checked
into this scaffold. Run the following from `app/` to materialise it:

```bash
flutter create --platforms=ios --project-name supporters_bus_app .
```

Then in Xcode:

- Set the deployment target to iOS 13.
- Enable **Push Notifications** capability.
- Enable **Background Modes → Remote notifications**.
- Add the `GoogleService-Info.plist` you receive from
  `flutterfire configure` to the Runner target.
