# ADR NNNN — Title

- **Status**: proposed | accepted | superseded by ADR-XXXX
- **Date**: YYYY-MM-DD
- **Decider(s)**: who approved this decision

## Context

What problem are we solving? What constraints (technical, operational,
regulatory, social) make this decision necessary or non-trivial? Capture
the state of the system *before* this change, including any previously
considered alternatives that have already been rejected.

## Decision

The decision, in one or two sentences. Then expand:

- which approach was chosen,
- what concrete changes follow (code, schema, infra),
- what we explicitly chose *not* to do.

## Consequences

- **Positive** — what improves (security, latency, dev velocity, cost).
- **Negative** — what gets harder, what new failure modes are introduced.
- **Follow-up** — work this decision creates (migrations, deprecations,
  tracking issues).

## Alternatives considered

For each alternative: short description, why it was not chosen, and the
trade-off we accepted.
